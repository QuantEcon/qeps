## Summary

This QEP proposed a protocol for running a project that named no platform: where a
project's goal, state and history live, how a decision is recorded, and how one working
session hands over to the next, with a records folder in each repository. A second QEP
was to bind the protocol to GitHub.

It was withdrawn on 2026-11-17, before a decision. A protocol with a separate binding
defined every concept twice, and there is no plan to change platform. An audit also
found that the records folders only grew, and that agents read old notes in them as
rules in force. The parts worth keeping were folded into a single, shorter proposal on
project trackers and working records
([QuantEcon/qeps#44](https://github.com/QuantEcon/qeps/pull/44)).
